# Basic Web and Linux Concepts

## 1. WSL

**WSL (Windows Subsystem for Linux)** is a Windows feature that allows users to run a Linux environment directly on Windows.

## 2. Linux

**Linux** is an open-source, Unix-like operating-system kernel used to build Linux operating systems such as Ubuntu and Debian.

## 3. Unix

**Unix** is a family of operating systems developed earlier than Linux and is widely used in servers and enterprise systems.

## 4. Public IP

**Public IP** is an IP address used to identify a device or service for communication over the public Internet.

## 5. Private IP

**Private IP** is an IP address used to identify a device within a private network such as a home, office, or cloud network.

## 6. Client

**Definition:** A client is a device or application that sends a request to a server.

**Simple example:**

When you open **Google Chrome** and search for something, Chrome is the **client**.

```text
You → Chrome (Client) → Request
```

## 7. Server

**Definition:** A server is a computer or application that receives requests from clients and sends responses.

**Simple example:**

When Chrome asks Google for search results, Google's server receives the request and sends the results back.

```text
Client → Server → Response
```

## 8. Web Server

**Definition:** A web server receives HTTP requests from clients and sends web content as a response.

**Simple example:**

You type a website address in Chrome:

```text
Chrome
   ↓
Web Server
   ↓
Web Page
```

For example, **Nginx** receives the request and sends the website's files to your browser.
