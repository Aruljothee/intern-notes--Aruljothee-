### 1.What is HTTP Protocol?
HTTP(HyperText Transfer Protocol) is a set of rules used for communication between a client and a server on the web.
Example:
Browser sends a request and server sends a response.

### 2.What is a web application?
A web application is a software application that users access through a web browser.
Example:
Gmail,Online banking,Online shopping websites.

### 3.what is a web server?
A web server is a computer or software that receives requests from clients and sends back web content or responses.
Example:
Browser asks for a webpage and web server sends the webpage.

### 4.What is HTTPS and why it is secure?
HTTPS(HTTP Secure) is HTTP communication protected by TLS encryption.
Example:
As it provides Integrity,Authentication etc..

### 5.What are authentication and authorization?
Authentication means checking who you.
Example:
You enter your username and password and the system will verifies you.

Authorization means checking what you are allowed to do.
Example:
You are logged in,but only admin can delete users.

### 6.How does social login work?
Social login allows you to sign in to an application using an account from a provider such as Google.
The application uses login provider for verification.

### 7.What is synchronous vs asynchronous communication?
Synchronous communication means the sender waits for a response before continuing.
Example:
Application A sends a request,waits,receives response and continues.

Asynchronous communication means the sender can continue working without waiting for the response immediately.
Example:
Application A senda a request and continues working by which response comes later.

### 8.What is REST?
REST(Representational State Transfer) is an architectural style of designing web APIs.
It commenly uses HTTP methods such as:
1) GET - retrieve data
2) POST - create/send data
3) PUT - replace data
4) PATCH - update part of data
5) DELETE - remove data
example:
GET /products (used to retrieve products).
