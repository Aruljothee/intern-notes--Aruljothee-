# Week 5 – Virtualisation and Containers

## Lab 5: Dockerising the Books API

### Objective

Learn how to package and run a Spring Boot REST API using Docker containers.

### Project

**Books API** – A Spring Boot REST API for managing books.

### Topics Covered

- Virtual machines and containers
- Docker images and containers
- Dockerfile and `.dockerignore`
- Building and running Docker images
- Docker networking
- PostgreSQL container with persistent storage
- Docker CLI commands
- Publishing an image to Docker Hub

### Project Folder

`books-api/`

### Docker Hub

[aruljothee/books-api](https://hub.docker.com/r/aruljothee/books-api)

### Technologies

Java, Spring Boot, Maven, Docker, PostgreSQL

### Result

The Books API was packaged into a Docker image and published to Docker Hub.
