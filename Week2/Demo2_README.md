# Demo 2 – Basic Authentication Spring Boot Application

This project is a **Basic Authentication Spring Boot Application** that provides user registration and user management operations using REST APIs. It uses **Spring Security with HTTP Basic Authentication**, **BCrypt password encryption**, **Spring Data JPA**, and **MySQL** for database storage.

The application allows users to register, view users, update users, and delete users. User registration is accessible without authentication, while the other user operations require authentication.

# Technologies Used

* Java 17
* Spring Boot 3.5.5
* Spring Web
* Spring Data JPA
* Spring Security
* MySQL
* Hibernate
* Maven
* BCrypt Password Encoder
* Swagger / OpenAPI
* HTTP Basic Authentication
