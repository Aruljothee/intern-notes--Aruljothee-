# Demo 3 & 4 – Social Authentication Spring Boot Application

This project is a **Social Authentication Spring Boot Application** that provides user authentication using **Google OAuth2 Login** and REST APIs for user management. It allows only the configured admin Google account to access the application and assigns the **ADMIN role** after successful authentication.

The application also uses **environment variables** to securely store the Google Client Secret and MySQL Database Password instead of keeping them directly in the source code.

# Technologies Used

* Java 17
* Spring Boot
* Spring Web MVC
* Spring Data JPA
* Spring Security
* OAuth2 Client
* Google OAuth2
* MySQL
* Hibernate
* Maven
* Swagger / OpenAPI
* REST APIs
* Role-Based Authorization
* Environment Variables
* OAuth2 Client Secret Protection
* Database Password Protection
