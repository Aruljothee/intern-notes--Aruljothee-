# Demo 1 – No Authentication(Employee Management Application)

This project is an **Employee Management Spring Boot Application** that provides employee management operations using REST APIs. It uses **Spring Web**, **Spring Data JPA**, **Spring Security**, and **MySQL** for database storage.

The application allows users to create, view, update, and delete employee records. **No authentication is required**, so all employee management operations are accessible without authentication.

# Technologies Used

* Java 17
* Spring Boot 4.1.1
* Spring Web MVC
* Spring Data JPA
* Spring Security
* MySQL
* Hibernate
* Maven
* REST APIs
